## Completed Assignments

### Assignment 1 - Automated EC2 Instance Management

**Objective:**
Automatically stop EC2 instances tagged `Action=Auto-Stop` and start EC2 instances tagged `Action=Auto-Start` using AWS Lambda and Boto3.

### AWS Services Used

- AWS Lambda

- Boto3 (Python)
