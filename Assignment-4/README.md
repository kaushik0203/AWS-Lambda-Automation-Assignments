# Assignment 4 – Automated Amazon EBS Snapshot Creation

## Objective

Create an AWS Lambda function to automate EBS snapshot creation.

## AWS Services Used

- Amazon EC2
- Amazon EBS
- AWS Lambda
- IAM
- CloudWatch
- Python (Boto3)

## Implementation

- Identified attached EBS volumes.
- Created snapshots using Boto3.
- Verified snapshot creation from the AWS Console.

## Output

Lambda successfully created snapshots for attached EBS volumes.
