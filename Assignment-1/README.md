# Assignment 1 – Automated EC2 Instance Start/Stop

## Objective

Create an AWS Lambda function that automatically:

- Starts EC2 instances tagged for auto-start.
- Stops EC2 instances tagged for auto-stop.

## AWS Services Used

- Amazon EC2
- AWS Lambda
- IAM
- CloudWatch
- Python (Boto3)

## Implementation

- Created two EC2 instances.
- Tagged instances for Auto-Start and Auto-Stop.
- Configured IAM permissions.
- Developed and deployed a Lambda function.
- Tested the automation successfully.

## Output

The Lambda function automatically started and stopped EC2 instances based on their tags.
