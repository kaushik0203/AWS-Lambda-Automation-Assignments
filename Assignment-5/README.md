
# Assignment 5 – Automated EC2 Instance Tagging

## Objective

Create an AWS Lambda function that automatically applies tags to EC2 instances missing the required tag.

## AWS Services Used

- Amazon EC2
- AWS Lambda
- IAM
- CloudWatch
- Python (Boto3)

## Implementation

- Created an EC2 instance.
- Developed a Lambda function to identify instances without the required tag.
- Automatically applied the missing tag.
- Verified successful tagging.

## Output

The EC2 instance was automatically tagged after Lambda execution.
