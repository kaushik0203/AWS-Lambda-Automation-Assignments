# Assignment 2 – Automated Amazon S3 Object Cleanup

## Objective

Create an AWS Lambda function that automatically deletes objects older than the configured retention period from an S3 bucket.

## AWS Services Used

- Amazon S3
- AWS Lambda
- IAM
- CloudWatch
- Python (Boto3)

## Implementation

- Created an S3 bucket.
- Uploaded sample files.
- Developed a Lambda function to identify old objects.
- Deleted matching objects automatically.
- Verified successful execution.

## Output

Old S3 objects were removed successfully through Lambda automation.
