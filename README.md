# AWS Lambda Automation Assignments

## Overview

This repository contains AWS Lambda automation assignments developed using **Python (Boto3)** and various AWS services. Each assignment demonstrates serverless automation for common cloud administration tasks.

## Technologies Used

- AWS Lambda
- Amazon EC2
- Amazon S3
- Amazon EBS
- AWS IAM
- Amazon CloudWatch
- Python 3.x
- Boto3

## Repository Structure

```
AWS-Lambda-Automation-Assignments/
│
├── Assignment-1/
├── Assignment-2/
├── Assignment-4/
├── Assignment-5/
└── README.md
```

## Assignments

### Assignment 1
Automated EC2 Instance Start/Stop using AWS Lambda and Boto3.

### Assignment 2
Automated S3 Object Cleanup based on object age.

### Assignment 4
Automated Amazon EBS Snapshot Creation.

### Assignment 5
Automated EC2 Instance Tagging.
